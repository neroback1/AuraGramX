## 12.10.0 (1274)

Documented on September 2, 2026. Channel publication and newer releases should be checked in the official download channel.

- Reduced unnecessary notification batching delay while preserving the existing other-device grace behavior.
- Improved connection recovery scheduling when network availability changes.
- Added access to the Android background-service notification category settings without disabling the reception service itself.
- Includes the AuraGramX notification icon work and existing customization, local-history and OCR features.

These changes are not a promise of instant notifications on every phone. Physical-device background-delivery testing remains dependent on the user's device, network and battery policies.
